## Live Website

[Open the MSQ website](https://mrreikol.github.io/WEB-Assignment-3/)

## About the project

This is a student website for MSQ, a clothing store in Kazakhstan. It helps visitors explore clothes, check the size guide, learn about the brand and contact the store. The design uses the MSQ logo, neutral colors and product photos supplied for the project.

## Pages

- `index.html` — home page and featured products.
- `catalog.html` — six products with descriptions, prices, sizes and WhatsApp links.
- `size-guide.html` — size table and measuring instructions.
- `about.html` — information about MSQ.
- `contact.html` — store details, a 2GIS location link and an example contact form.

## Features and technologies

- HTML5 semantic elements: header, nav, main, section, article and footer.
- Headings, paragraphs, lists, images, links, a table and a form.
- A separate CSS file for every HTML page.
- Flexbox for navigation and featured products; CSS Grid for the hero and catalog layout.
- Relative and absolute positioning for the New labels.
- Media queries at 768px and 480px for tablet and mobile layouts.
- Local Bootstrap 5.3.3 CSS with containers, rows, columns, spacing utilities, tables, buttons and form styles.
- Navigation and a footer on all five pages.
- WhatsApp links for product enquiries and a 2GIS link for the store location.
- Product photos edited with AI to use the same size and a consistent studio background.

The website uses HTML, CSS and Bootstrap CSS. It does not use JavaScript.

## How to run

Extract the project folder and open `index.html` in a browser. Keep the `css`, `bootstrap` and `images` folders next to the HTML files. No installation or build command is required.

## Project notes

This is an independent educational project. Prices and size-table measurements are examples; current prices, stock and sizes should be confirmed with the store. The contact form demonstrates HTML form structure and does not send messages. Visitors can contact the store through WhatsApp or phone links.
